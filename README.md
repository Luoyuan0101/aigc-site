# AIGC 领域调研 · 我的方向：AIGC 动漫动画生成器

> AI 前沿挑战实验室 · 任务三「项目方向调研」成果
> 网站是这份调研的**交付载体**；调研的落点是「在 AIGC 领域做什么」——
> 我选定的方向是 **AIGC 动漫角色 / 剧情动画生成器**。

## 这个网站讲什么

按「**是什么 → 现在在做什么 → 案例 → 局限 → 我的方向**」一条线组织：

| 页面 | 路径 | 内容 |
| --- | --- | --- |
| 首页 | `/` | AIGC 一句话定义、关键数据（DAA）、五大方向速览、我的方向速览 |

| 案例 | `/cases` | **动漫生成赛道**、开源基础模型、教育实践、学生项目、建站与内容工具 |

| 我的方向 | `/direction` | **AIGC 动漫动画生成器**：超详细分类体系 + 要求规整模板 + 流程 / 工具 / 阶段 / 风险 |

## 我的方向（`/direction`）包含什么

1. **定位**：一句话说明做什么、给谁用、核心难点、预期产出
2. **分类体系（一）动画表现形式**
   - 8 种视觉风格（日式赛璐璐 / 厚涂 / 三渲二 / 国风水墨 / Q 版 / 小清新 / 像素 / 实时 3D）
   - 8 种运动生成方式（动态漫画 / 逐镜图生视频 / 首尾帧 / 文生视频 / 动作迁移 / 补帧 / 有限动画 / 面部口型驱动）
3. **分类体系（二）生成技术路线**：8 条，每条列清优势、代价、代表工具、适用场景、难度
4. **分类体系（三）要求规整模板**：9 组、49 个字段（基本设定 / 视觉风格 / 角色设定 / 场景美术 /
   镜头分镜 / 声音 / 生成参数 / 交付合规 / 质量验收），每项给出填写示例
5. **完整流程**：剧本 → 角色资产 → 分镜静帧 → 动态分镜 → 逐镜生成 → 声音 → 剪辑 → 质检合规 → 导出
6. **工具选型表**：按环节给出候选工具与注意事项
7. **三阶段推进**：单镜 15 秒 → 完整 60 秒 → 模板变工作台，每阶段都有验收标准
8. **风险与边界**：7 条风险的应对 + 4 条明确不做的事

## 技术栈

- **Next.js 14**（App Router）—— 组织页面与路由
- **TypeScript** —— 类型检查，编译期就能发现写法问题
- **Tailwind CSS 3** —— 直接写样式类，不单独维护 CSS 文件

## 本地怎么跑起来

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev
# 终端会输出 http://localhost:3000

# 3. 浏览器打开（地址粘贴到顶部地址栏，不是搜索框）
#    http://localhost:3000

# 4. 停止：在终端按 Ctrl + C
```

打生产包（可选）：

```bash
npm run build && npm start
```

## 目录结构

```
aigc-site/
├── app/                    # 页面（App Router）
│   ├── layout.tsx          # 全局骨架：导航栏 + 页脚
│   ├── page.tsx            # 首页
│   ├── globals.css         # 全局样式与 Tailwind 引入
│   ├── what/page.tsx
│   ├── trends/page.tsx
│   ├── cases/page.tsx
│   ├── limits/page.tsx
│   └── direction/page.tsx
├── components/
│   ├── Nav.tsx             # 顶部固定导航（含移动端菜单）
│   ├── Footer.tsx          # 页脚（含来源导航）
│   └── ui.tsx              # 通用组件：标题、卡片、标签
├── lib/
│   └── content.ts          # 全站文字内容集中在这里，改文案只改这个文件
├── tailwind.config.ts      # 配色、字体、阴影、动画
└── package.json
```

> 想改内容？绝大多数情况下只需要动 `lib/content.ts`。
> 想改配色？动 `tailwind.config.ts` 里的 `colors`。
